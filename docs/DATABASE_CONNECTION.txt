======================================================
CARGAEXPRESS - CONEXIÓN A BASE DE DATOS
======================================================

TIPO: MySQL 8+

HOST:    configurado por variable DB_HOST
PUERTO:  3306 (por defecto, configurable DB_PORT)
DB:      cargaexpress
USUARIO: configurado por variable DB_USER
PASS:    configurado por variable DB_PASSWORD

-----------------------------------
CONFIGURACIÓN EN EL BACKEND
-----------------------------------
Archivo: config/database.ts

  host:     env.get('DB_HOST')
  port:     env.get('DB_PORT')
  user:     env.get('DB_USER')
  password: env.get('DB_PASSWORD')
  database: env.get('DB_DATABASE')
  ssl:      env.get('DB_SSL', false) ? { rejectUnauthorized: false } : undefined

-----------------------------------
ORIGEN DE DATOS
-----------------------------------
La BD se aprovisiona desde Railway (plugin MySQL).
Las variables de entorno se definen en Railway Dashboard > Variables.

Para entorno local:
  1. Copiar .env.example a .env
  2. Completar los valores DB_HOST, DB_USER, DB_PASSWORD, DB_DATABASE
  3. Ejecutar migraciones: node build/ace.js migration:run --force

-----------------------------------
ESQUEMA
-----------------------------------
  Usuarios (users):             id, nombre, apellido, email, password, telefono,
                                 edad, rol (cliente|conductor|admin), suspendido,
                                 fcmToken, avatar, ...
  Conductores:                  id, userId, placa, tipoVehiculo, capacidad,
                                 calificacion, totalViajes, ...  
  Viajes (trips):               id, clienteId, conductorId, origen, destino,
                                 distancia, monto, estado, ...
  Ofertas (offers):             id, tripId, conductorId, monto, estado, ...
  Notificaciones:               id, userId, tipo, titulo, mensaje, leida, ...
  Refresh tokens:               id, userId, token, expiresAt
  Configuracion plataforma:     id, tarifaBase, tarifaKm, radioBusqueda, ...
  Reportes:                     id, reporterId, tipo, descripcion, estado, ...
  Disputas:                     id, tripId, userId, motivo, estado, ...
  Comunicados:                  id, autorId, titulo, contenido, estado, ...
  Encuestas:                    id, autorId, titulo, preguntas, estado, ...
  Pagos (payments):             id, userId, monto, comprobanteUrl, estado, ...
  Comisiones (deudas):          id, conductorId, monto, pagada, ...
  Favoritos (favorite_routes):  id, userId, nombre, origen, destino, ...
  Foro:                         id, autorId, titulo, contenido, fijado, ...
  Moderator reports:            id, moderatorId, conductorId, motivo, ...
  Backups logs:                 id, archivo, tamaño, estado, ...
  Mensajes chat:                id, tripId, senderId, mensaje, ...
  Emergencias:                  id, userId, ubicacion, estado, ...
  Encuesta respuestas:          id, encuestaId, conductorId, respuestas, ...
